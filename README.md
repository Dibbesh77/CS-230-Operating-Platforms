# CS 230 – Operating Platforms

## Reflection

The Gaming Room wanted to expand their Android game Draw It or Lose It into a web-based application that supports multiple users and platforms. The goal was to design a scalable system.

I did well in organizing the design document and explaining system architecture, requirements, and platform comparisons.

The design document helped me plan the system before coding and understand how everything connects.

If I could improve one part, I would make the UML diagram clearer and easier to understand.

I used object-oriented design and client-server architecture. In the future, I will continue using UML and cloud-based design approaches.
